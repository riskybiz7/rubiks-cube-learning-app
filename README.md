# Rubik's Cube learning app

A web app for learning to solve a 3x3 Rubik's Cube: the beginner (daisy) method
for first-timers, CFOP algorithms for faster solvers. It shows the cube in 3D,
animates each algorithm, and walks you through solving your own scrambled cube,
entered by hand or, later, scanned with your camera.

**Status:** design phase. See `docs/decisions-log.md`.
